# Cách chạy

## Backend
```
cd backend
```

Tạo file env như sau:
```
PORT=3000
MONGO_URI=<một URI nào đó mà test>
```

rồi `npm run dev` hoặc `node server.js`

## Frontend
```
cd ..
```

rồi `npm run dev`
